## Entry requirements

Add an entry only when it links to one of the following:

- a reviewed technical guide;
- a reproducible lab or production-style project;
- a measured performance or failure-recovery experiment;
- an architecture decision record;
- an incident or troubleshooting exercise using synthetic data; or
- a public, verifiable credential.

Passing an exam establishes a credential milestone. The engineering evidence in this repository establishes what can be designed, built, explained, and operated.
